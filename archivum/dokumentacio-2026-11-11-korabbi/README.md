# Megőrzött dokumentációs előzmény

Ezek a fájlok a `16527e0` oldalváltozathoz tartozó, korábban bővített dokumentáció másolatai a mostani egyeztetés előttről. Tartalmazhatnak időközben felülírt megfogalmazást, például a korábbi CTA-feliratot vagy idézetstílust. A folyamat előzményeit őrzik, nem aktuális megvalósítási utasítások.

A követendő források a projekt `tervezes/` mappájának briefje, design-system.md, szovegek.md és aktualis-oldalterkep.md fájlja; a beadási állapotot a `beadas/README.md` foglalja össze. A honlap megtartott megjelenési alapja továbbra is `16527e0`.
